# API and Contract Companions

This directory contains human-readable companions for source-level contracts.

These documents are not the highest authority. For Phase 1 cross-layer contracts:

- Decision authority: `docs/decisions/0007-phase1-cross-layer-contracts.md`
- Type authority: `src/contracts/phase1.ts`
- Companion: `phase1-contracts.md`

When a contract changes, update the ADR or source type first, then update the companion document.
