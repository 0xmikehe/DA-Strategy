# ADR-0005: 策略层方法论基线（策略为第一公民 · 信号→动作映射归策略 · 版本化复盘 · AI 仅润色）

- 状态：Accepted
- 日期：2026-06-16
- 决策者：hashmike + Claude Code
- 涉及层：strategy（决策层）；消费 signal 的「活跃信号集 + 快照 ID」与 ledger 的「策略归属持仓与成交 + 现金流」

## 背景

策略层（决策层）即将进入子 PRD 撰写，是三层中最后一层、也是闭环的收口处：它把判断层的客观信号、账本层的账户事实，收敛成「基于判断该做什么 + 做得好不好」。验收标准 = 决策好不好。

与信号层（ADR-0004）同理，先于具体策略，须把一套**方法论**框死：策略会随时间增删、规则会反复改、复盘结论会反哺规则——若不先把「策略是什么、怎么消费信号、怎么版本化、怎么复盘、AI 能碰到哪」定死，功能一多就会侵蚀「可复盘、可证伪、可淘汰」的信条（典型侵蚀：用后视镜改写历史决策、让 AI 代替人拍板、绩效不对基准而自我感觉良好）。

本 ADR 把这套方法论定死，作为策略层每一次开发的共同地基。具体的策略实例、阈值、再平衡参数、全局风险层的数值不在此 ADR，归策略层 PRD 与各策略卡 / 策略档案。

核心信条（贯穿全项目）：**系统中不存在不被复盘检验的模块（含 AI）。**

## 决策

### 1. 策略为第一公民，全局只保留薄风险层

- **策略是自包含的完整对象**：资金上限、基准、资产池子集、验证周期、入场/出场/加减仓规则、再平衡规则、失效条件、复盘口径、版本号、当前状态——全部下沉到策略对象内定义（立项书 §5）。
- **薄全局风险层只做三条约束**，除此之外一切归策略：① 加密总投入上限；② 稳定币最低保留比例；③ 单资产跨策略合计上限。三者是**硬约束**（任何策略不得击穿），具体数值与个人总净资产挂钩，由人配置、可审计。
- **不在策略之上叠加复杂的全局调度/择时层**：避免再造一个「不可证伪的顶层大脑」，与信号层「不做单一综合市场状态」（ADR-0004 决策 1）同一种克制。

### 2. 信号→动作的映射归策略，决策层永不读原始行情

- **生产消费分离的落地**（承接 ADR-0004 决策 1）：信号层只陈述客观事实（`btc_trend = 下降`）；**「这意味着该减仓 / 该无视 / 阈值多少」是策略层的解读**，写在策略规则里，不回灌信号层。
- **决策层只消费「活跃信号集 + 快照 ID」**（总 PRD §1.4 契约1），**永不直接读原始行情**，也永不绕过信号层自算指标。需要新维度 → 去信号层加信号，不在策略层私接行情。
- 只有**启用**态信号可被策略消费（观察/影子态不可见于策略，ADR-0004 决策 4）；信号开关变动会改变策略可见的信号集，故每个决策都要绑定当时的 `snapshot_id` 以还原「当时看到哪些信号、取值是什么」。
- 同一批信号原子被不同策略各自配置阈值与动作——这正是「信号库不因新增策略而膨胀」的另一半（ADR-0004 决策 1 的消费侧对应）。

### 3. 策略规则版本化，历史按当时版本复盘（只追加）

- **规则任一处变更即产生新版本号**；旧版本不删（只追加，呼应账本「事实只追加」、信号「定义只追加」）。
- **每笔成交绑定其发生时生效的策略版本**（`exchange_trade_fill.strategy_version`，账本 PRD §1.4.5 已落字段，由账本侧按成交 `time` 取当时版本）；复盘报告标注所依据的版本。
- **禁止后视镜**：不得用今天的规则解释昨天的成交，不得静默改写历史决策依据——这是「决策可复盘」的物理前提。

### 4. 决策可复盘：每个决策绑定快照与版本

- 策略层产生的每个**决策事件**（仓位计划、再平衡触发、执行偏离判定、复盘结论）都要可追溯到：当时的 `snapshot_id`（市场判断依据）+ `strategy_version`（规则依据）+ 输入事实（账本持仓）。
- 复盘通过 `snapshot_id` 还原任意历史时点的判断依据（总 PRD §1.4 契约3），通过 `strategy_version` 还原当时的规则——二者缺一，复盘就有后视镜偏差。

### 5. 执行偏离是客观标记，不做心理归因

- 用**客观的执行偏离观察**取代「情绪化操作」自我申报（立项书 v0.2 变更4、§12.5）：每笔成交相对策略规则，**客观记录**是否偏离计划价格区间 / 计划仓位 / 计划时点，以及交易频率是否异常。
- **只做客观标记，不做心理归因**（不写「我当时贪婪了」）。偏离判定的输入是账本成交事实 + 策略规则 + 绑定快照，可证伪、可复盘。
- 人可补充少量「执行理由」作为决策上下文，但这是事实记录，不是系统的心理分析。

### 6. 绩效双轨且永远对基准；跑不赢基准即淘汰信号

- **TWR 衡量策略能力、MWR 衡量实际资金效果，两者并列展示**（立项书 §12.2）；存在持续追加/撤出资金时简单收益率失效，故双轨是硬要求。
- **充提划转必须入账**（账本层提供现金流事实，策略层据此切分 TWR 的子区间），否则收益率失真。账本只记事实、不算收益率；**TWR/MWR 的计算口径归策略层**（账本 PRD §0.3）。
- **每个策略的绩效永远与其自身基准并列**（中长期配置策略基准 = BTC 定投并持有）。**若策略长期跑不赢自身基准，其复杂度净价值为负，应淘汰**——这是策略最重要的、可证伪的失效条件（立项书 §5 基准定义）。

### 7. 复盘闭环：系统生成草稿 → 人确认 → 反哺规则（新版本）

- 复盘是**有「待办—完成」状态的工作流**，不是看板（总 PRD §2.4）。
- 流程：**系统按周期自动生成复盘草稿**（基于真实账本数据 + 快照 + 规则）→ **人逐项确认产出结论** → 结论可触发策略规则修改（→ 决策 3 新版本），形成闭环。
- 复盘口径**分离**：执行纪律按周验证，策略有效性按策略自身验证周期（中长期可能需一个完整市场周期 2–4 年）验证；季度复盘只评估「是否按规则运行」，不轻易下「策略有效/无效」结论（立项书 §14.3）。
- **人是唯一拍板者**：系统只生成草稿与客观标记，结论由人确认；复盘结论改变规则是「闭环真正反哺决策」的验收点（立项书 §15.10、§19.2 失效条件2）。

### 8. AI 在策略层只做文字润色，不碰决策

- 策略层是 AI 边界最严的一层。Phase 1 AI 在本层**仅限角色：复盘报告草稿的文字润色 / 信息整理**（立项书 §十）。
- **明确不用于**：仓位建议、择时、价格预测、自动决定买卖、自动改写策略规则、自动归因下结论。这些都属「人拍板」范畴。
- 与信号层的区别：信号层 AI 可作「被回测的信号源」（角色 A，ADR-0004 决策 6）；**策略层 AI 连信号源都不是**——它不产出被消费的取值，只把人已确认的事实整理成可读文字。理由同 ADR-0004：决策依据必须人可审计可争论，黑箱决策正是本系统要消灭的。

### 9. 策略层不持久化派生，从账本事件流 + 策略定义回放算出

- 持仓、成本、已实现/未实现盈亏、TWR/MWR、偏离、再平衡缺口——**全部由账本事件流（策略归属的成交+现金流）+ 策略规则定义回放现算**，源头永远是账本事件流与策略定义，不在策略层另存一份派生真相（呼应账本 PRD §1.6 纯函数回放）。
- 好处同账本层：任意历史时点账面 = 把 `asOf` 设为该时刻；个人现货中长期量级下回放为毫秒级，无需投影表。

### 10. 范围：Phase 1 单策略实例化，策略发现推迟 Phase 2

- **Phase 1 只做一个策略实例**：加密现货多资产中长期配置策略（基准 BTC 定投并持有），按策略对象 schema 硬编码实例化；策略对象 schema 本身要为多策略设计好，但 Phase 1 只激活一个（呼应账本物理子账户 Phase 1 仅激活 1 个）。
- **策略发现（假设库、纸面跟踪机制、小仓验证机制、多策略状态流转）属 Phase 2**（总 PRD §3.3 范围排除、立项书 §17 Phase 2）。策略状态机的全套状态（观察/纸面/小仓验证/运行/暂停/淘汰）在 schema 中预留，Phase 1 主要走「运行」一态。

## 备选方案

- **把择时/调度放到策略之上的全局层**：弃。会再造一个不可证伪的顶层大脑，与「策略为第一公民、全局只薄风险层」冲突；信号的解读应分散到各策略规则里。
- **策略直接读行情自算指标**：弃。违背总 PRD §1.4 契约1，且会与信号层重复造轮子、绕开「可证伪信号 + 快照」的复盘地基。
- **简单收益率 / 只用一种收益率**：弃。有持续充提时简单收益率失效；TWR 与 MWR 各答不同问题（能力 vs 资金效果），必须并列。
- **让 AI 给仓位建议 / 自动归因下结论**：弃，见决策 8。决策依据须人可审计；AI 在本层只润色人已确认的事实。
- **绩效不对基准、只看绝对收益**：弃。牛市里绝对赚钱不等于策略有价值；不对基准就无法证伪「这套复杂度是否值得」，等于放弃「可淘汰」。
- **持久化策略持仓/绩效派生表**：弃（Phase 1）。与账本同理，全量回放在本项目量级下足够，增量投影对乱序/版本切换敏感，复杂度不划算。

## 影响

- **策略层 PRD**：各章引用本 ADR，不重述；策略对象 schema、信号消费契约、版本化、偏离、绩效、复盘、AI 边界成为 PRD 各章地基。
- **信号层**：本 ADR 落实其「生产消费分离」的消费侧；策略只消费**启用**态信号 + 快照 ID，不新增对信号层的要求。
- **账本层**：策略层消费账本「策略归属持仓与成交 + 现金流事实」，TWR/MWR 口径归策略层（账本 PRD §0.3 已划界，无需改账本）；`strategy_version` 绑定字段账本侧已落（账本 PRD §1.4.5）。
- **前端**：策略页/复盘页按「策略为第一公民 + 写操作面极小（修改策略=新版本、确认复盘）」实现，沿用视觉契约（ADR-0002）。
- **后续**：`docs/strategies/`（一策略一档案，承载「可淘汰」，与 `docs/signals/` 对称）的约定与「新增一个策略的 checklist」在落地第一个具体策略卡时建立，引用本 ADR；薄全局风险层三条数值待人按总净资产配置。
