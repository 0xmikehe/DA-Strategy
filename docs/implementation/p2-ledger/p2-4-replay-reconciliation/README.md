# P2-4 Replay and Reconciliation

This phase defines how ledger source facts replay into computed balances, how computed balances are compared with reported `account_balance_snapshot` records, and how reconciliation differences are classified.

Canonical files for this phase:

- `design.md` - replay and reconciliation design.
- `plan.md` - P2-4 implementation plan.
- `verification.md` - create during implementation to record evidence.
