# P2-4 Replay and Reconciliation

This phase will define how ledger source facts replay into computed balances, how computed balances are compared with reported `account_balance_snapshot` records, and how reconciliation differences are classified.

Canonical files for this phase:

- `design.md` - create when the reconciliation design is ready for review.
- `plan.md` - create after design approval.
- `verification.md` - create during implementation to record evidence.
