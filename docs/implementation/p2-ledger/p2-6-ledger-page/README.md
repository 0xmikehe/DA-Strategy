# P2-6 Ledger Page

This phase defines the thicker ledger page: source mode, sync freshness, reconciliation panel, pending attribution queue, external trade entry, binding/key health display, and safe write affordances.

Frontend implementation must follow `design/数字资产投资操作系统_视觉说明.html` and ADR-0002.

Canonical files for this phase:

- `design.md` - ledger page design.
- `plan.md` - P2-6 implementation plan.
- `verification.md` - create during implementation to record evidence.
