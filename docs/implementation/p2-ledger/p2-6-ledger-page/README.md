# P2-6 Ledger Page

This phase will define the thicker ledger page: source mode, sync freshness, reconciliation panel, pending attribution queue, external trade entry, binding/key health display, and safe write affordances.

Frontend implementation must follow `design/数字资产投资操作系统_视觉说明.html` and ADR-0002.

Canonical files for this phase:

- `design.md` - create when the ledger page design is ready for review.
- `plan.md` - create after design approval.
- `verification.md` - create during implementation to record evidence.
