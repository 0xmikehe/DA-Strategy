# P2-7 Remote Operations

This phase will define remote runtime hardening: deployment, live smoke commands, backup/restore rehearsal, logging redaction, alerting, and operational runbooks.

Remote operations must not weaken the read-only API boundary or expose secrets in logs, exports, UI, or notifications.

Canonical files for this phase:

- `design.md` - create when the remote operations design is ready for review.
- `plan.md` - create after design approval.
- `verification.md` - create during implementation to record evidence.
