# Agent Drafts and Redirects

This directory is reserved for historical agent-generated drafts and redirects.

Canonical project documentation should live in:

- `docs/prd/`
- `docs/decisions/`
- `docs/research/`
- `docs/api/`
- `docs/business/`
- `docs/strategies/`
- `docs/implementation/`

When a draft here becomes part of the project, migrate or absorb it into the appropriate canonical directory and leave a short redirect stub at the old path when useful.
